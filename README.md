# Copilot-prompt-lab-files
Lab files for Microsoft Copilot Prompt sessions

## What is a Prompt-a-thon?

A Prompt-a-thon is an immersive interactive learning event to educate participants about how to effectively use GenAI tools to enhance their productivity.

## Goals of a Prompt-a-thon

- **Skill-building:** learn how to turn a problem into a clear task.
- **Experimentation & Innovation:** Experiment with ideas, discover new workflows, and build confidence through hands-on experimentation.
- **Efficiency & Time-Saving:** convert slow, manual tasks into Copilot workflows.
- **Organizational/Institutional:** Accelerate AI readiness across the institution and surface practical use cases that solve institutional pain points.
- **Collaboration & Knowledge-Sharing:** Build a shared library of high-quality prompts and encourage collaboration across departments.
